# Word 实验报告排版规范（可选插件）

本文档定义中文理工科实验报告在 Microsoft Word（`.docx` / `.doc`）环境下的排版工程准则。
本模块作为独立可选插件存在，**默认不启用**。仅当用户显式要求排版或明确确认后方可激活。

---

## 一、 启用排版

1. **后置收尾原则**：
   排版工作严格定位为文稿最终交付前的**收尾渲染工序**。必须在全部五道审核工序均已通过、全文内容最终定稿后，方可启动排版模块将文本注入 Word 模板并应用本规范。
2. **显式询问原则**：
   在接收到实验报告撰写或润色任务时，若用户未明确提出排版需求，主线程必须用自然语言显式询问：
   > *“文稿语言审改已准备就绪。请问本次是否需要启用【Word 排版模块】（负责 8523 dxa 居中基准、空行控制、代码框流式跨页、注释垂直对齐、大章节分页、西文字体选用及 OMML 原生公式处理）？若不需要，将默认仅对文稿进行语言与逻辑审查。”*
3. **保守默认**：
   若用户未作明确指定、未明确确认或回复不需要，**默认坚决不启用排版模块**，全流程保持原有的纯文本/Markdown 语言审改。

## 二、 核心工程参数速查

| 参数项 | 标准数值 / XML 属性 | 约束说明 |
| :--- | :--- | :--- |
| **页面边距** | 左边距 $1418\text{ dxa}$（$25.0\text{ mm}$），右边距 $1361\text{ dxa}$（$24.0\text{ mm}$） | 正文版心宽度为 $9127\text{ dxa}$（$161.0\text{ mm}$） |
| **容器基准宽度** | 定死为 $8523\text{ dxa}$（$150.3\text{ mm} \approx 426.15\text{ pt}$） | 数据表与 1×1 代码框统一采用该宽度，左右各留 $302\text{ dxa}$ 呼吸留白 |
| **容器水平对齐** | `<w:jc w:val="center"/>`（水平居中） | 数据表与代码框均必须显式居中 |
| **大章节分页** | 核心一级大标题设置 `<w:pageBreakBefore/>` | 正则匹配 `^[一二三四五六七八九十]+、`，强制另起新页 |
| **代码单行容量** | Consolas 11pt 下安全容量为 $68$ 字符 | 长度 $\le 68$ 字符的代码行严禁非必要折行 |
| **代码跨行缩进** | 软换行符（`\x0b`）+ 挂起缩进（Hanging Indent） | 逻辑单行跨行折行时，续行对齐在首行括号或层级内侧 |
| **行尾注释对齐** | 同一代码块内自适应列垂直对齐 | 以块内最长代码自适应确定基准列，双斜杠 `//` 竖直方向严格对齐 |
| **独立长注释** | 整行 `//` 注释行 | 顶格或跟随作用域缩进，严禁向右列对齐推移 |
| **空行控制** | 代码框上不空下空；数据表与插图上下皆空 | 隔离空行统一为 $11\text{ pt}$ 独立空段落（Spacer） |
| **中西文字体** | 中文宋体；代码 Consolas 11pt；英文字符/数字/硬件缩写 Times New Roman 11pt | 严禁将 GPU、CPU、RAM 等通用缩写设为 Consolas |
| **数学公式** | Word 原生 OMML 矢量对象（`m:oMath`） | 单字母变量斜体，数字及多字母符号直立体 |

## 三、 模块化细则子手册索引

本排版规范已拆分为以下专项子手册，供各环节精准查阅：

1. **[references/typesetting_spacing_geometry.md](typesetting_spacing_geometry.md)**（《版面几何与空行规范》）：
   - 详细规定页面左右边距、容器 $8523\text{ dxa}$ 居中基准、一级大标题分页控制及空行三态法则。
2. **[references/typesetting_code_blocks.md](typesetting_code_blocks.md)**（《代码排版与注释规范》）：
   - 详细规定代码框跨页流式切分（严禁整行 cantSplit）、68 字符单行容量限制、超长逻辑单行代码跨行内在缩进（挂起缩进对齐括号）、行尾注释垂直列对齐及独立长注释顶格分工。
3. **[references/typesetting_fonts_math.md](typesetting_fonts_math.md)**（《字符字体与公式规范》）：
   - 详细规定中文字体、代码字体与散文/缩写英文字体的精确映射，以及 Word 原生矢量数学公式（OMML）生成准则。
4. **[references/typesetting_self_referential_case.md](typesetting_self_referential_case.md)**（《经典基准案例：排版参考样例》）：
   - **核心基准参考**：短小精干的全要素自指范文，每一句话与代码均自指说明自身排版规则，并配有一页式实际渲染效果图。
5. **配套工程脚本**：
   - [scripts/word_layout_engine.py](../scripts/word_layout_engine.py)：Word 紧凑排版渲染引擎（支持尺寸收窄、注释自适应对齐、跨行挂起缩进与格式导出）。
   - [scripts/check_layout.py](../scripts/check_layout.py)：Word 报告机械静态排版合规检查器。
